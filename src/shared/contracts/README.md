# Contratos compartidos

DTOs y contratos de la API compartidos como referencia entre el backend (.NET) y
el frontend (Flutter). El diseño de los contratos REST está en
[`../../../docs/09-api-rest.md`](../../../docs/09-api-rest.md).

> Nota: backend y frontend usan lenguajes distintos (C#/Dart). Los contratos se
> mantienen sincronizados generando los modelos Dart a partir del esquema
> **OpenAPI** que publica la API. Esta carpeta documenta y versiona ese esquema.
